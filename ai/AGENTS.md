# Repo Context Pack

This repo is Damien Murphy's personal Astro blog, based on AstroPaper and
branded as "Forged". It is a static GitHub Pages site at
`https://forged.damienmurphy.net/`. Its field notes connect software
engineering with personal systems, resilience, work, organisations, learning,
and life.

## Stack

- Astro 6, TypeScript, Tailwind CSS v4, and pnpm.
- Node.js 22.12 or newer is required; CI and deployment use Node.js 24.
- Markdown and MDX content are supported.
- Pagefind provides static search.
- Content lives in `src/content/posts` and `src/content/pages`.
- Main config files:
  - `astro-paper.config.ts`: user-facing site, theme, feature, social, and content settings.
  - `src/config.ts`: resolved config with defaults.
  - `src/types/config.ts`: config type definitions.
- Build and validation commands:
  - `pnpm run validate:posts`
  - `pnpm run lint`
  - `pnpm run format:check`
  - `pnpm run build`
- `pnpm run build` runs Astro type/content checks, builds the site, generates
  Pagefind indexes, copies the indexes to `public/pagefind`, and validates RSS.

## Content Model

Blog posts use the Astro content collection in `src/content.config.ts`.

Required post frontmatter:

- `title`
- `description`
- `pubDate`
- `tags`

Optional post frontmatter:

- `author`
- `modDate`
- `slug`
- `featured`
- `draft`
- `series`
- `ogImage`
- `canonicalURL`
- `hideEditPost`

Use `pubDate` and `modDate` exactly, with date-only `YYYY-MM-DD` values.

Draft posts are excluded by default and can be previewed locally with
`pnpm dev:drafts`. Future-dated non-draft posts are visible in development but
excluded from production until `pubDate`.

Tags drive the site's topic taxonomy and tag pages. Keep tag spelling and casing
consistent: differently cased or slug-like values may be treated as separate
tags.

Series are derived entirely from post frontmatter. The post with `series.order:
1` must provide the stable lowercase-hyphenated `id`, `title`, and
`description`. Later posts provide `id` and a unique positive integer `order`.
Series are ongoing by default; the highest-order post may set `complete: true`.
The build rejects incomplete or conflicting series metadata.

## Routing

- Posts are rendered by `src/pages/[...slug]/index.astro`.
- Post URLs are generated by `src/utils/getPostPaths.ts`.
- Subdirectories under `src/content/posts` become part of the URL.
- A post's optional `slug` overrides its filename-derived root-level path and
  may contain nested path segments.
- Route segments are normalized with `slugify`.
- Builds fail when posts resolve to duplicate URLs or use reserved top-level
  routes such as `/about`, `/archives`, `/posts`, `/search`, or `/tags`.
- `/posts/` is retained for the paginated post listing only.
- `/tags/` is presented as Explore and contains both series and topics.
- Series indexes are generated at `/series/[id]/`.
- Home page shows featured posts first, then recent posts from `getSortedPosts`.
- Sorting uses `modDate` when present, otherwise `pubDate`.

## Styling

- Global styles: `src/styles/global.css`.
- Theme tokens: `src/styles/theme.css`.
- Main layout width uses `.app-layout` and `.max-w-app`.
- Application UI uses IBM Plex Mono; prose uses Source Serif 4.
- Light accent: `#006b78`.
- Dark accent: `#c98968`.
- The site supports light and dark themes.
- Use existing Astro components and Tailwind utility style before introducing new abstractions.

## Features and Publishing

- The homepage shows up to 6 recent non-featured posts after all featured
  posts. Paginated post listings show 12 posts per page.
- Dynamic OG images are generated for posts without a custom `ogImage`.
- `public/default-og.jpg` is the custom static fallback image for the site.
- GitHub Pages deployment runs on pushes to `main`, manual dispatches, and
  daily at 00:15 UTC so scheduled posts can become available without a new
  content commit.

## Important Gotchas

- The README is project-specific high-level orientation, while implementation
  and configuration files remain authoritative.
- There is currently no post template. Use `src/content.config.ts` as the
  source of truth when creating frontmatter.
- `astro-paper.config.ts` is the source of truth for public site identity, social links, edit-post links, timezone, and metadata.
- `tags.minimumPosts` controls how many published posts a tag needs before it appears in the tag directory.
